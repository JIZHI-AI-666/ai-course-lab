# 出题

## 提示词

```text
【角色】你是国际中文教育助教，输出由教师审核后使用。
【任务】只依据所给短文生成5道阅读选择题：2道细节、2道词义、1道主旨。每题4选项、唯一答案、原文依据。
【要求】
1. 输出表格：题号、题型、题干、A、B、C、D、答案、依据。
2. 正确答案必须有原文支持；错误选项可设置干扰，但不得在解析中作为事实。
3. 材料不足以支持5题时明确说明，不通过续写补情节。
4. 题型配比严格为2+2+1；答案位置尽量分散；采用已学词表，难词需标待核对。
【示例】材料：周六，小林和朋友约好九点在公园见面。他坐公交车出门。路上车很多，他晚到了十分钟。朋友还在门口等他。两人拍了照片，中午在附近吃饭。

|1|细节|小林怎么去公园？|走路|坐公交车|骑车|坐地铁|B|坐公交车出门|

|3|词义|晚到是什么意思？|迟到|早到|离开|没到|A|约好九点但晚十分钟|
|4|词义|附近是什么意思？|很远|里面|离这里不远|昨天|C|在公园附近吃饭|
|5|主旨|短文主要说什么？|公交车价格|一次周末见面|朋友的工作|拍照的方法|B|出发、见面和活动经过|
【粘贴区】
（填写材料、学习目标、学生水平及已学词表。缺材料时先列缺项，不编造。）
```

## 适用说明

用于课文后的阅读练习。更换题型时同时修改配比与示例。先验证原文依据，再检查干扰项是否造成多解。
