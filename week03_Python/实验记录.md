# W3 实验记录：词汇练习生成器

## 本周完成内容

- 从 `data/生词表.csv` 读取词汇，并按 HSK 等级筛选。
- 默认生成按词性分组的造句练习；也可以使用 `--mode fill` 生成填空题。
- 无论从哪个工作目录运行，脚本都会以自身所在的 `week03_Python/` 定位 `data/`，并将 `练习.txt` 写在本周目录内。

## 本周新知识点

1. **列表推导式**：`[word for word in words if ...]` 可以简洁地筛选符合条件的词条。
2. **字典的 `setdefault()`**：先为新词性创建空列表，再追加词条，适合做分类输出。
3. **文件编码**：读写中文文件时应明确使用 `encoding="utf-8"`，避免不同系统出现乱码。
4. **路径定位**：程序不应依赖终端的当前目录；`Path(__file__).resolve().parent` 能稳定定位本周目录。

## 运行记录

```bash
# 默认：按词性分组造句
python week03_Python/vocab_tool.py

# 可选：生成填空题
python week03_Python/vocab_tool.py --mode fill
```

本次示例数据中，HSK4 词条有 4 个：`把字句`、`商量`、`感动`、`坚持`。
