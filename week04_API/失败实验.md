# 第四周失败实验

实际复测日期：2026-10-26。以下均在本机进行，不发送真实云端请求、不产生模型费用。

## 1. 缺少密钥

子进程设置空的DEEPSEEK_API_KEY，执行当前入口。退出码：1。

```text
错误：未配置有效的 DEEPSEEK_API_KEY。
处理：复制 .env.example 为 .env，填入自己的密钥后重试。
```

结果：给出配置办法，没有未处理堆栈。

## 2. 连接失败

将测试客户端指向本机不可达地址127.0.0.1:1，timeout=1、max_retries=0，使用无效占位值作本地测试。没有断开整机网络，也没有把真实密钥发给其他地址。退出码：1。

```text
错误：无法连接 API，请检查网络和 BASE_URL。
```

结果：APIConnectionError被转换为友好提示。该测试验证连接失败分支，不等于云端限流、认证或余额不足的实测。
