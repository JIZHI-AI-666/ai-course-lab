## R2 增加原句定位、封闭错因与禁止代写

完整提示词：
```text
你是国际中文教师。批改完全虚构的短文。依次输出优点、问题、修改建议。每个问题引用原句，标注错因，给出可替换句及原因；错因只选语序、搭配、关联词、时量、结构助词。不能确定的标待核对，不凑错误，不改写整篇，不增加人物经历。限400字。
短文：昨天我去图书馆。我看书两小时了。我很高兴的。虽然下雨，所以我还是去了。
```

模型原始输出：
```text
**优点**：句子简短，时间、地点、事件清楚；“虽然……还是……”表达转折意愿可理解。

**问题与修改建议**：
1. 原句“我看书两小时了。”错因：时量。动作已完成，不宜用“了”表持续。可替换：“我看书看了两小时。”原因：用动词重叠式“看了”引出时量补语。
2. 原句“我很高兴的。”错因：结构助词。形容词谓语句末一般不用“的”。可替换：“我很高兴。”原因：删除多余“的”。
3. 原句“虽然下雨，所以我还是去了。”错因：关联词。“虽然”应与“但是/还是”呼应，不能与“所以”搭配。可替换：“虽然下雨，但是我还是去了。”原因：转折关联词配套使用。

**待核对**：无。
```
