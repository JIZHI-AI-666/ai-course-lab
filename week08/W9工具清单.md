# W9 预习：希望助手拥有的两个工具

W9 讲工具调用——让助手不只会答，还会「用工具」。按讲义要求，下面列出两个我希望 `assistant_v1.py` 拥有的工具，每个都写清输入与输出。

选这两个的理由：它们正好落在助手现在做不到的地方。W7 的 `vocab_tool.py` 已经能读生词表、筛选、统计，第 3 周的代码里就有现成能力，但 `assistant_v1.py` 现在只能答、不能查——「这个生词在三级词表里吗」这种问题，它只能靠模型记忆编一个答案。两个工具都是**查已有文件**而不是生成内容，正好对应讲义说的「给 LLM 一个可调用的函数接口」。

---

## 工具 1：查生词表

**用途**：回答某个词是否在某个等级的生词表里、属于哪个等级。用于备课时确认词汇难度，或学生问「这个词是不是 HSK4 的词」。

**输入**

| 参数 | 类型 | 说明 | 必填 |
|---|---|---|---|
| `word` | string | 要查询的词语，如「犹豫」 | 是 |
| `level` | string | 目标等级，一至三级 / 四至六级 / 七至九级，可留空查全部 | 否 |

**输出**

| 字段 | 类型 | 说明 |
|---|---|---|
| `found` | boolean | 是否在生词表中命中 |
| `level` | string \| null | 命中所在等级；未命中为 `null` |
| `word_type` | string \| null | 词性（名词/动词/形容词等）；未命中为 `null` |
| `source` | string | 命中的数据文件与行号，供人工核对 |
| `message` | string | 未命中时说明「该词不在生词表中」，而不是让模型自己编一个等级 |

**在 v1.0 里的接入位置**：`answer()` 收到问题后，先判断是否命中工具关键词（如「生词」「词表」「等级」），命中则调用本工具取结果，把结果拼进提示词的 `<资料>` 段，再交给 `LLM().ask()`。

**一个要注意的点**：本工具的输出必须是**结构化事实**，不能让模型自己补写。`word_type` 查不到就返回 `null`，不要让模型猜——这正是 W7 幻觉对照表里那个「3245 被答成 1000」的同类风险，工具存在的意义就是把这类问题从「凭记忆」改成「查表」。

---

## 工具 2：算分

**用途**：把 HSK 四级真题或自编练习按标准答案自动判分，输出总分、得分率与错题清单。用于课堂小测后的即时反馈。

**输入**

| 参数 | 类型 | 说明 | 必填 |
|---|---|---|---|
| `answers` | list[string] | 学生作答数组，如 `["A", "B", "C", "D"]` | 是 |
| `key` | list[string] | 标准答案数组，长度须与 `answers` 一致 | 是 |
| `items` | list[object] | 可选，题目与分值明细；不传则每题等权 | 否 |

**输出**

| 字段 | 类型 | 说明 |
|---|---|---|
| `total` | number | 总分 |
| `score` | number | 得分 |
| `correct_count` | number | 答对题数 |
| `total_count` | number | 题目总数 |
| `wrong_items` | list[object] | 错题清单：题号、我的作答、正确答案、该题分值 |
| `comments` | string | 一句反馈，如「错 2 题，都是形近词，建议复习第 3 周词表」 |

**在 v1.0 里的接入位置**：同上，命中判分意图则调用工具，把判分结果作为资料传给模型，模型只负责把分数解释成教学建议，不负责算术。

**一个要注意的点**：`total` 和 `score` 必须由代码算出，不能让模型口算。模型的角色是把「8 题对 6 题」翻译成「形近字辨析」这类可执行建议——这个翻译它做得好；0.75 × 100 这种算术它做不好。同理，`wrong_items` 的题号与正确答案必须来自 `key` 数组，不能是模型复述的。

---

## 两个工具的共同设计原则

1. **工具给事实，模型给解释。** 查生词表给等级，算分给分数；模型负责组织语言与教学建议，不负责产出事实本身。
2. **查不到就明确说查不到。** 参照 `build_prompt` 里已有的「资料中没有的内容就如实说『资料中未提及』」，工具同样返回 `null` / `message`，不给模型留编造空间。
3. **输出可核对。** 每个工具都带 `source` 或标准答案数组，人能回查原始文件或输入，不用相信模型的转述。

这两个工具都复用第 3 周 `vocab_tool.py` 和 `week07_RAG` 已有的数据与读取能力，不引入新的数据源——延续 W8「组装而非重写」的做法。
